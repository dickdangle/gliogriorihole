hanzi gravity / count k

Characters fall into orbit by frequency.

This local sim treats each Hanzi character as a body with mass based on count K, where K = frequency count in the input text. More frequent characters become heavier, pull harder, and render larger. Paste Hanzi text, load a file, or use the built-in sample corpus.

The current local Hanzi files don’t actually contain Hanzi, so this ships with a built-in sample and lets you paste or upload your own text.
